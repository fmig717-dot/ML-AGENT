# Trading-бот в Telegram — деплой

Этот бот — облачная версия тех же трёх skill'ов (`buyer-finder`, `offer-drafter`,
`market-supervisor`), которые раньше работали только внутри Claude Code на вашем
компьютере. Теперь с ними можно работать прямо из Telegram, 24/7, без открытого
терминала.

**Важно про безопасность и секреты**: все шаги ниже, где нужно создавать аккаунты
или вводить пароли/ключи/токены — вы делаете САМИ, в своём браузере. Агент
(Claude), который помог собрать этот бот, не создаёт облачные аккаунты и не вводит
реальные секреты за вас — это прямое правило безопасности, не прихоть.

## Что получится

- Пишете боту в Telegram на русском: «найди покупателей для CFA», «подготовь
  волну КП», «покажи buyers.xlsx» — бот читает те же skill-файлы, что и раньше,
  и выполняет ту же работу через Anthropic API.
- Доступ к Gmail (создание/чтение черновиков) — опционально, см. шаг 3.
- Данные (buyers.xlsx, kp_state.json, вложения) живут на постоянном диске
  хостинга, НЕ в этом репозитории — такими они и должны оставаться.
- Отвечает только вам (белый список Telegram id) — остальным бот молчит.

## Шаг 1. Создайте Telegram-бота (5 минут)

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, задайте имя.
2. BotFather выдаст токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — это `TELEGRAM_BOT_TOKEN`, сохраните, пригодится на шаге 4.
3. Напишите **@userinfobot** — он покажет ваш числовой Telegram user id
   (не username!) — это `ALLOWED_TELEGRAM_USER_IDS`.

## Шаг 2. Anthropic API-ключ

1. console.anthropic.com -> API Keys -> Create Key.
2. Это `ANTHROPIC_API_KEY`. Учтите: каждое сообщение в боте тратит реальные
   токены вашего аккаунта (как обычный API-доступ, отдельно от лимита Claude Code).

## Шаг 3. Gmail (опционально — без этого бот работает, но без создания черновиков)

Выполните **локально, на своём компьютере** (не на сервере бота):

```bash
cd bot
pip install google-auth-oauthlib
python3 gmail_oauth_setup.py --client-id ВАШ_CLIENT_ID --client-secret ВАШ_CLIENT_SECRET
```

Подробная инструкция, где взять `--client-id`/`--client-secret` (через
console.cloud.google.com, без прохождения верификации приложения — достаточно
режима "Test users") — в начале файла `bot/gmail_oauth_setup.py`, прочитайте
перед запуском. Скрипт откроет браузер, вы залогинитесь в свой Google-аккаунт
и разрешите доступ только к черновикам (не ко всей почте), скрипт напечатает
`GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` / `GOOGLE_REFRESH_TOKEN` — сохраните
для шага 4.

## Шаг 4. Деплой на Railway (бесплатный тир достаточен для старта)

1. railway.app -> зарегистрируйтесь (через GitHub — удобнее всего).
2. "New Project" -> "Deploy from GitHub repo" -> выберите репозиторий
   `fmig717-dot/ML-AGENT`.
3. В настройках сервиса (Settings):
   - **Root Directory**: `/` (оставить корень репозитория — Dockerfile лежит
     в `bot/Dockerfile`, но ему нужен доступ к `.claude/skills` из корня).
   - **Dockerfile Path**: `bot/Dockerfile`.
4. "Variables" -> добавьте по одной все переменные из `bot/.env.example` со
   своими реальными значениями (TELEGRAM_BOT_TOKEN, ALLOWED_TELEGRAM_USER_IDS,
   ANTHROPIC_API_KEY, и если настроили Gmail — три GOOGLE_*). `DATA_DIR` можно
   оставить `/data`.
5. "Settings" -> "Volumes" -> "Add Volume" -> mount path `/data`. **Это
   обязательно** — без постоянного диска вся история (buyers.xlsx, номера КП)
   будет стираться при каждом редеплое.
6. "Deploy". Через пару минут в логах должна появиться строка
   `Бот запущен, разрешённые user id: {...}`.
7. Напишите боту в Telegram `/start`.

Если предпочитаете не Railway — тот же `Dockerfile` (build context = корень
репозитория, путь `bot/Dockerfile`) подойдёт для Render, Fly.io или любого
VPS с Docker; везде нужны те же переменные окружения и постоянный диск на `/data`.

## Проверка перед тем, как считать бота готовым

- `/start` отвечает только вашему Telegram-аккаунту (проверьте с другого
  аккаунта, что бот молчит — это нормально и ожидаемо).
- Попросите «покажи список доступных скриптов» — должны вернуться
  `kp_number`, `record_draft`, `build_buyers_xlsx`, `append_row`.
- Если настраивали Gmail — попросите «покажи последние черновики» и
  убедитесь, что не возвращается ошибка "Gmail не настроен".

## Известные ограничения этой версии

- Нет поддержки файловых вложений к письмам через Telegram-бота (как и в
  прежних правилах offer-drafter: по умолчанию вложения не нужны, КП — это
  текст письма; см. `.claude/skills/offer-drafter/rules.md` §5).
- Веб-поиск для buyer-finder работает только если ваш Anthropic-аккаунт
  поддерживает серверный инструмент `web_search` — если нет, бот тихо
  продолжит без него (упадёт обратно на то, что знает сам, и скажет об этом).
- История переписки хранится по `chat_id` без дополнительного шифрования на
  диске `/data` — это тот же уровень защиты, что у остальных файлов volume.
