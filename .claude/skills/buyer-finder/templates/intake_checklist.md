# Чек-лист вводных (шаг 1)

Используй как внутреннюю шпаргалку, чтобы ничего не забыть спросить. Задавай вопросы
своими словами, компактно, и только то, что пользователь ещё не дал сам.

## Продукт/услуга
- [ ] Название и короткое описание
- [ ] HS-код (если известен)
- [ ] Базис поставки (Incoterms: FOB / CIF / EXW / DAP и т.п.)
- [ ] Объём предложения / MOQ
- [ ] Цена или вилка цены (если готовы её называть на этом этапе)

## Документы
- [ ] Спецификация товара
- [ ] Коммерческое предложение (КП) — текст, файл или пересказ

## Правила
- [ ] Обязательные формулировки (например "Soft commercial offer" в подходе к письму)
- [ ] Шаблон подписи отправителя
- [ ] Ограничения: регионы/страны, в которые нельзя предлагать (санкции и т.п.)
- [ ] Любые другие требования к тону/формату письма

## Регион
- [ ] Страна или группа стран для поиска покупателей
- [ ] Есть ли предпочтение по типу покупателя (импортёр / дистрибьютор / конечный
  производитель-потребитель), если пользователь уже знает
