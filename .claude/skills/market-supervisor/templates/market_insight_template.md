# Как записывать рыночный инсайт

Каждая находка (тренд, цена конкурента, упоминание на форуме, научная статья про
применение продукта) — одна строка в листе "Рынок и тренды" через `scripts/append_row.py`:

```
python3 .claude/skills/market-supervisor/scripts/append_row.py output/buyers.xlsx "Рынок и тренды" \
  --field "Дата=22.10.2026" \
  --field "Продукт=CFA" \
  --field "Источник=<название источника + ссылка/где искали>" \
  --field "Инсайт/тренд=<что конкретно нашли, 1-3 предложения>" \
  --field "Рекомендация (цена/подход)=<что это значит для нашей цены/аргументов — если применимо>" \
  --field "Статус=Зафиксировано"
```

## Поле "Статус"

- `Зафиксировано` — просто информация в архив, без прямого влияния на КП.
- `Предложено к КП (ждёт утверждения)` — инсайт достаточно значим, чтобы предложить
  изменить `content/<PRODUCT>/kp_master_content.md`. В этом случае ОБЯЗАТЕЛЬНО также
  добавь запись в `content/<PRODUCT>/changelog.md` со статусом "Предложено" и сообщи
  пользователю отдельно — не меняй сам файл содержания без подтверждения (правило 2 из
  rules.md).
- `Учтено после одобрения` — пользователь подтвердил, изменение внесено в
  `kp_master_content.md`, changelog обновлён на "Утверждено".

## Источники — без выдумывания

Как в buyer-finder: ссылайся на реально найденные источники (конкретный сайт, статья,
форум, база цен). Если что-то не удалось подтвердить — пиши "не найдено", не
придумывай правдоподобные цифры.
