# Фиксированная подпись (HTML)

Используй этот блок как есть в конце `htmlBody` каждого письма/драфта — без изменений,
без персонализации. Вставляй его сразу после текста предложения (можно отделить
горизонтальной линией `<hr>` для визуальной границы).

```html
<p>Best Regards,<br>
Fadei Migalcian<br>
Trading Department FITO VITA SRL<br>
<a href="mailto:f.mig717@fitovita.eu">f.mig717@fitovita.eu</a><br>
<a href="https://www.fitovita.eu/trading">www.fitovita.eu/trading</a></p>
```

## Plain-text вариант (для поля `body`)

Если собираешь и plain-text альтернативу (`body`) — используй:

```
Best Regards,
Fadei Migalcian
Trading Department FITO VITA SRL
f.mig717@fitovita.eu
www.fitovita.eu/trading
```

(в plain-тексте гиперссылки просто текстом — это нормально, почтовые клиенты сами
подсвечивают email и домен как ссылки).
